# Ford Car Price Prediction 

A machine learning project that predicts Ford car prices using Linear Regression, achieving an R² score of 83%.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- SciPy
- Jupyter Notebook

## Project Workflow
- Data Cleaning and Preprocessing
- Exploratory Data Analysis (EDA)
- Categorical Feature Encoding
- Feature Selection
- Linear Regression Model Training
- Model Evaluation

## Features
The model uses car specifications such as:
- Manufacturing Year
- Mileage
- Tax
- MPG (Miles Per Gallon)
- Engine Size
- Car Model
- Transmission
- Fuel Type

## Model Performance
- **Algorithm:** Linear Regression
- **R² Score:** 0.83 (83%)
